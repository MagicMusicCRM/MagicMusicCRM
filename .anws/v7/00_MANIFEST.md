# .anws v7 — Финансово-учебная модель

**Дата создания:** 2026-08-07  
**Статус:** Active  
**Предыдущая версия:** v6

## Цели версии

Свести личный счёт, покупку и отмену абонемента, списание часов занятия,
оплату преподавателя и постоянные расписания в одну атомарную,
настраиваемую и проверяемую модель без потери финансового аудита.

## Основные изменения

- атомарная покупка абонемента с личного счёта владельца или другого клиента;
- независимо настраиваемые директором типы списаний и оплаты преподавателя,
  которые сотрудник явно выбирает для каждого расчётного действия;
- единый обязательный workflow переноса занятия из всех экранов;
- группировка постоянных расписаний с активной и завершённой историей;
- безопасная отмена абонемента со сторно вне обычной статистики продаж;
- упрощение Client Card: действия внутри профильных разделов и общая заметка.
