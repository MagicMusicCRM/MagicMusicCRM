# MagicMusicCRM Light Design Lab

Отдельный интерактивный дизайн-стенд. Он не подключён к production API,
не меняет Flutter-приложение и использует только локальные тестовые данные.
Это визуальный click-through: кнопки открывают нужные экраны, панели и окна,
но расчёты, сохранение и другие бизнес-операции не выполняются.

## Запуск

```powershell
npm install
npm run dev
```

Адрес по умолчанию: `http://127.0.0.1:4178/`.

## Что включено

- роли директора, управляющего, администратора, преподавателя и клиента;
- отдельная роль системного администратора;
- каталог из 202 связанных экранов и визуальных состояний;
- реальные верхнеуровневые разделы каждой роли;
- рабочие вкладки, поиск, фильтры, формы, таблицы, диалоги и панели;
- разовое занятие с проверкой конфликтов и ранжированными вариантами;
- план постоянного расписания;
- отдельный каталог базовых компонентов и состояний;
- окно обновлений без кнопки ручного скачивания.
