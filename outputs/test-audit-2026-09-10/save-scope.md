# Сохранение изменений аудита тестов

Базовый Git HEAD: `3815e1f54`. В рабочей копии до аудита уже находились
незакоммиченные изменения приложения, сервера, миграций и API-контрактов.
Они не включены в коммит инфраструктуры тестов.

Новые test-tools, Flutter tooltip guard, Jest config, команды тестирования,
руководство и результаты аудита сохранены обычными файлами коммита.
В `server/package.json` сохранены только изменения существующих команд тестов
и новые `test:full` / `test:tools`; прежние изменения зависимостей исключены.

## Изменения поверх ранее несохранённых API-контрактов

Файлы `scripts/check-api-contracts.ps1`, `scripts/check-expense-contract.ps1`
и `docs/engineering/API-CONTRACTS.md` существовали до аудита, но ещё не были
добавлены в Git. Их исходное содержимое не принадлежит этому изменению.
Наши правки этих файлов и аргумента `test:contracts` в `server/package.json`
сохранены отдельно в [preexisting-contract-edits.patch](preexisting-contract-edits.patch).
Для первых трёх файлов базой служат их копии в
`dist/release218/source-selected/`; patch содержит только разницу с этой базой.

В текущей рабочей копии patch уже применён. Повторно применять его не нужно.
Проверка `git apply --reverse --check` подтвердила соответствие сохранённой
разницы текущим файлам. Для восстановления в другом checkout сначала нужны
исходные API-contract файлы и команды из предшествующей работы, затем обычные
`git apply --check` и `git apply` для этого patch. Он не предназначен для
применения непосредственно к базовому HEAD без API-contract изменений.

Логи, временные результаты запусков и coverage остаются в локальной рабочей
копии; опубликованные в verification.md числа относятся к указанным запускам.
