### ✅ Решения владельца 16.07 — в коде

- **KVA-239 закрыт** (`e57064c7`): ставки педагога и подобная **поразрезная** фин. информация — админу и управляющему. Обще-суммарное (выручка/расходы/аналитика) осталось директору. Заодно ушла нестыковка: управляющий мог массово менять ставки, но не видел отчёт, из которого это делается.
- **Дата обращения — на стороне students** (`c26eb2eb`): лид из приложения получает датой момент своего появления здесь, у импортированного побеждает исходная дата HolliHop, при дедупе по телефону **данные HolliHop переживают слияние**.
- **Оплата/переплата по абонементу — по личному счёту** (`2ad8b6ef`): «Оплачено» = приход счёта за абонемент, «Переплата/Долг» = приход − стоимость.
- **Firebase настроен и проверен** (`797dfe66`): ключ в локальном `server/.env`, `TASK_REMINDERS_ENABLED=true`. Проверено не на глаз — тем же способом, что и провайдер (`google-auth-library` JWT), запрошен access token, **Google его выдал**.

### ⏳ Осталось (не код)

1. **Ключи Firebase + напоминания на ПРОД.** Локальный env — это dev (`localhost:54329`). На прод нужны `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` и `TASK_REMINDERS_ENABLED=true`.
   - ⚠️ **Не включайте напоминания раньше ключей.** Без них push возвращает `skipped/not_configured`, но маркер напоминания одноразовый и сгорает всё равно → задача молча теряет напоминание навсегда.
2. **Выгрузки HolliHop для импортёра** — `tasks.json` / `task-history.json` / `students.json` / `leads.json` (по возможности с колонкой `ID клиента`), затем dry-run. Код и инструкция готовы: [`hollihop-exports-runbook.md`](import/hollihop-exports-runbook.md).
3. **Прогон на устройстве.** ⚠️ **Приложение не запускалось ни разу** — всё держится на тестах и анализаторе. Руками стоит проверить: звук, экран дня, пикеры, CSV-экспорт, ленту истории задач, правку/отмену записи личного счёта.

### ❌ Невозможно (с обоснованием)

- **Комментарии, задачи с историей и поурочная оплата — в API HolliHop их НЕТ.** Все методы 404, полей оплаты не существует. Проверено живым ключом заказчика. Единственный источник — файловые выгрузки. См. §6 и [`hollihop_api_probe_2026-07-16.md`](import/hollihop_api_probe_2026-07-16.md).
