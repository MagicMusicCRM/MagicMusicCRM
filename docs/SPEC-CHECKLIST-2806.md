### ❌ Невозможно (с обоснованием)

- **Поурочная оплата педагогам.** В `EdUnits` нет ни одного поля `Price/Pay/Rate/Cost/Salary`; `GetPayments` — платежи клиентов. Backfill `lessons.teacher_rate` невозможен, нужна отдельная выгрузка с суммами.
  - ⚠️ Уточнение 17.07: в `Days[]` есть `TeacherPayableMinutes` — но это **минуты, а не деньги**. Ставку из них не вывести.
- **Backfill привязки «платёж → занятие» из HolliHop.** В API платежи есть (`GetPayments`: `ClientId`, `Date`, `Value`), но занятия в них нет — только клиент и дата. Ссылку задним числом заполнять неоткуда; импортированные платежи останутся без неё, и это норма (см. §2.3).

⚠️ **Отсюда убрано «комментарии и задачи с историей — невозможно».** В API их действительно нет (все методы 404), но вывод «взять неоткуда» был неверен: и то, и другое приехало из файловых выгрузок 17.07 — **12 483 задачи, 11 960 событий истории, 1 742 комментария лидов, 7 476 заметок к занятиям**. «В API нет» ≠ «нет нигде».

Новый `crm.service.ts` + старый `crm.controller.ts` = сборка не собирается.
- **Возврат учёток упал на репетиции** — и это лучшее, что могло случиться. Заметил, восстановил. Мутировать надо копией или после коммита.
- **Дважды чуть не оставил «молчаливую ложь».** Сначала написал привязку платежа к занятию подзапросом: чужое занятие тихо превратилось бы в «не привязан», и тот, кто привязывал, ушёл бы уверенный, что привязал.
