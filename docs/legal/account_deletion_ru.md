# Удаление аккаунта MagicMusicCRM

Дата версии: 2026-05-30

Пользователь может запросить удаление аккаунта:

1. В приложении: `Профиль -> Удалить аккаунт`.
2. Через публичную веб-страницу удаления аккаунта: https://magicmusiccrm-legal.vercel.app/account-deletion/

После отправки запроса аккаунт переводится в статус обработки. ИП НАЗАРОВА НАТАЛИЯ НИКОЛАЕВНА и администрация Magic Music удаляют или обезличивают данные аккаунта, кроме записей, которые необходимо сохранить по закону, бухгалтерским, security- или антифрод-основаниям.

Минимальный текст для публичной страницы:

> Чтобы удалить аккаунт MagicMusicCRM, войдите в приложение и откройте `Профиль -> Удалить аккаунт`, либо отправьте запрос оператору приложения ИП НАЗАРОВА НАТАЛИЯ НИКОЛАЕВНА, ИНН 220418439440, ОГРНИП 323774600172671, с email аккаунта на `magicmusiccrm@gmail.com`. В запросе укажите email, использованный для входа. Мы обработаем запрос и удалим или обезличим связанные данные, кроме записей, которые обязаны хранить по закону.
