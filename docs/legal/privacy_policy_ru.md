# Политика конфиденциальности MagicMusicCRM

Дата версии: 2026-05-30

MagicMusicCRM используется для взаимодействия учеников, преподавателей, менеджеров и администрации школы Magic Music. Оператор приложения: ИП НАЗАРОВА НАТАЛИЯ НИКОЛАЕВНА, ИНН 220418439440, ОГРНИП 323774600172671.

## Какие данные обрабатываются

- данные аккаунта Google/Supabase: идентификатор пользователя, email;
- профиль: ФИО, номер телефона, роль в CRM, аватар, дата рождения при указании;
- учебные и CRM-данные: занятия, задачи, заметки, оплаты и связанные записи школы;
- сообщения, вложения, голосовые сообщения и объявления;
- push-токены Firebase Cloud Messaging для доставки уведомлений;
- технические данные, необходимые для безопасности, диагностики и работы приложения.

## Зачем используются данные

Данные используются для входа в приложение, маршрутизации пользователя по роли, связи со школой, отображения расписания, ведения учебной истории, работы чатов, отправки уведомлений, поддержки и обеспечения безопасности.

## Где хранятся и кому передаются данные

Данные хранятся и обрабатываются в Supabase, Firebase и инфраструктуре Magic Music. Оператором приложения является ИП НАЗАРОВА НАТАЛИЯ НИКОЛАЕВНА, ИНН 220418439440, ОГРНИП 323774600172671. Данные не продаются. Передача третьим лицам допускается только поставщикам инфраструктуры, по требованию закона или для защиты прав и безопасности пользователей и школы.

## Безопасность

Передача данных выполняется по HTTPS. Доступ к данным ограничивается аутентификацией, ролями пользователей, Row Level Security в Supabase и серверными проверками.

## Сроки хранения и удаление

Пользователь может запросить удаление аккаунта в приложении через `Профиль -> Удалить аккаунт`. После запроса данные аккаунта удаляются или обезличиваются, кроме записей, которые Magic Music обязана сохранить по закону, бухгалтерским, антифрод- или security-основаниям.
