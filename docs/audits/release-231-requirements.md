## Что сохраняется

Production 227–230: имя после покупки, общий колокольчик и inline Personnel, недельный график преподавателя, положительная доступность при настройке и часы филиала при её отсутствии. Сохраняются серверный RBAC/resource scope, expectedVersion/idempotency, append-only settlement/audit и действующие интеграции. Финансовые типы не раскрываются Teacher ради цвета карточки.

## Ограничения

REQ-013: точный набор 20→15 не повторялся в финальной серии; наличие файла не засчитывается как выполнение. Функциональные свойства счётчика проверяются отдельными текущими сценариями, см. evidence. REQ-029: компонентная проверка не является визуальной приёмкой всех settings страниц. Physical Windows IME, iOS/macOS, реальная отправка внешних сообщений/платежей и production backup не проверялись. Необязательные улучшения C из исходного аудита не включены в обязательную реализацию. Производительность измерена только для конкретной локальной групповой fixture.

Каждая требуемая доработка RC-01…RC-05 и её проверка описаны в отчёте кандидата. Неуспешные диагностические прогоны сохранены; они не суммируются с успешными как дополнительные завершённые сценарии.

Android Release: 70954806e6234f30a896540c082279ad — 23/0, Admin, обычный main, login/navigation/search/move/reopen и process restart. REQ-006/007 и мобильная доступность расписания дополнительно подтверждены после RC-05. Полная Windows матрица на Android не повторялась.
