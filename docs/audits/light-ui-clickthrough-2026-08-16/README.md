# Проверка контекстных окон и чатов

Дата: 2026-08-16

## Итог

Проверка подтвердила две корневые причины:

1. Диалоги и боковые панели рисовались поверх трёх универсальных пустых
   прямоугольников, а не поверх экрана, из которого они были открыты.
2. Чат смешивал нативный экран и универсальный шаблон с жёстко заданным
   собеседником. Поэтому переход формально менял адрес, но визуально открывал
   неверный или неполный контекст.

## Проверенные шаги

1. Карточка сотрудника до исправления: универсальный пустой фон.
2. Чат до исправления: отсутствовали папки обращений и часть переходов.
3. Карточка сотрудника после исправления: реальный список пользователей под
   диалогом, полноэкранное затемнение и явное закрытие.
4. Чат после исправления: папки «Лиды», «Ученики», «Архив», фильтр филиала,
   отдельные личные, групповые чаты и канал.
5. Создание чата: выбор группы или канала, затем соответствующая форма.
6. Открытый чат: поиск, сведения, вкладки материалов и отправка файла.

## Ограничения

Это визуальный click-through стенд. Проверены структура, видимые состояния и
переходы. Фактическая отправка сообщений, загрузка файлов и сохранение форм не
проверялись и намеренно не реализованы. Проверка снимков не доказывает полную
доступность с клавиатуры и программами чтения с экрана.
