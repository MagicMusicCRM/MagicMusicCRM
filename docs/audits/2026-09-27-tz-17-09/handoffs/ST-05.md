## Воспроизведение и evidence

Предусловия: собственный PostgreSQL 17 cluster на loopback, maintenance DB `/postgres`, Windows Flutter Debug, локальный NestJS; runner создаёт/удаляет отдельную временную DB. `HTTP_JOURNEY_ADMIN_URL` должен указывать только на этот cluster. Роли: director для редактора, admin/manager/director для trial, client и чужой manager для отрицательных проверок. Native harness использует API login и memory token/workspace, затем реальные product widgets; интерактивный login shell отдельно не проверялся. CRM stream и часть workers в этих режимах выключены; delivery/consumption ими не доказываются. Режимы запускались **отдельно и последовательно**:

```powershell
$env:HTTP_JOURNEY_ADMIN_URL = '<URL собственной loopback maintenance DB /postgres>'
node scripts/http-journey-check.cjs --audit-teacher-availability
node scripts/http-journey-check.cjs --audit-teacher-forms
node scripts/http-journey-check.cjs --audit-staff-forms
node scripts/http-journey-check.cjs --audit-plan-create
node scripts/http-journey-check.cjs --audit-group-plan
node scripts/http-journey-check.cjs --audit-customer-revisions
```
