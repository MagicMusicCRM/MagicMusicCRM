## Воспроизведение и evidence

Предусловия: Windows Flutter Debug, локальный NestJS и собственный PostgreSQL 17 на loopback. `HTTP_JOURNEY_ADMIN_URL` указывает только на maintenance DB `/postgres` собственного кластера; runner создаёт и удаляет отдельную временную БД на режим. Native harness использует реальные widgets, HTTP/backend/pg, но in-memory token/workspace storage. В первых семи режимах CRM invalidation stream отключён; X-03 использует реальный локальный stream, два staff UI и отдельный процесс клиента для повторного чтения ленты. Это не тест production, интерактивного login или долговременной сессии полной карточки. Для `--audit-tasks` включён локальный outbox worker. Режимы запускались **по одному**, последовательно:

```powershell
$env:HTTP_JOURNEY_ADMIN_URL = '<URL собственной loopback maintenance DB /postgres>'
node scripts/http-journey-check.cjs --audit-configuration
node scripts/http-journey-check.cjs --audit-navigation
node scripts/http-journey-check.cjs --audit-client-extended
node scripts/http-journey-check.cjs --audit-schedule-views
node scripts/http-journey-check.cjs --audit-finance-access
node scripts/http-journey-check.cjs --audit-partial-purchase
node scripts/http-journey-check.cjs --audit-tasks
node scripts/http-journey-check.cjs --audit-x03
```
