## Проверенные пути

| Entry point | Канонический путь | Защита commit |
|---|---|---|
| Разовое занятие | `LessonCommandService` → `ScheduleConstraintEngine` | advisory resource/client locks, повторная валидация внутри transaction, idempotency |
| Перенос | `LessonTransitionService` → тот же engine для frozen individual/group subject | reason, expected version, signed preview token, idempotent transaction |
| Plan preview/create/update | `SchedulePlanService` → engine для каждой строки, occurrence и участника | Plan/client/resource/series locks, version, idempotency, no PATCH при невалидном preview |
| Horizon worker | `ScheduleService.materializeSeries` → тот же engine | branch/series timezone, повторное чтение после locks, единая проверка всех участников, transaction rollback |
| Dashboard/Week/Day | единственный `CreateLessonDialog` | нет compact write-sheet и drag-and-drop mutation |
| Room availability | read-only occupancy projection | не пишет Lesson; UI не называет целый день «свободным слотом» |

## Закрытые дефекты

1. Horizon materializer использовал отдельный teacher/room-only SQL и мог
   пропустить client/group overlap, Branch hours/closed day, Teacher
   unavailability/assignment, Room Branch и duration conflict. Теперь он
   расширяет occurrence в timezone Branch/series и вызывает общий engine для
   каждого фактического участника.
2. Отбор живых series сравнивал `valid_until` только с московской датой. Теперь
   используется `coalesce(series.timezone_name, branch.timezone_name,
   'Europe/Moscow')`.
3. Plan и разовое занятие брали разные client lock keys (`student:*` против
   `client:student:*`). Ключ унифицирован.
4. `excludeScheduleSeriesIds` из-за SQL three-valued logic скрывал standalone
   Lesson с `series_id is null`. Условие исправлено для teacher/room/client.
5. Group overlap зависел только от текущего `group_students`. Теперь
   существующий Lesson использует immutable snapshot participant и остаётся
   blocker после изменения текущего состава.
6. Три параллельных запроса через один transaction `PoolClient` заменены
   последовательной проверкой; read-only pool preview остаётся параллельным.
7. Whole-day room occupancy больше не подписывается `Свободно/Занято`:
   используются честные `Без занятий/С занятиями`.
