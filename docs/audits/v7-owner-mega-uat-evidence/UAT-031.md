# UAT-031 — аудитории филиала

Статус: **PARTIAL**. Полный локальный UI/API/schema-кандидат пройден;
production owner Release-повтор mutation ещё не выполнен.

## Фактическая семантика удаления

Свободная аудитория не удаляется физически: Director после preview архивирует
её с причиной, датой действия, expected version, idempotency/audit/outbox и
append-only lifecycle history. Она исчезает из рабочих селекторов, но остаётся
доступной в архиве и может быть восстановлена. Такой путь сохраняет исторические
занятия, серии и планы.

Прямой `DELETE /crm/rooms/:id` fail-closed возвращает
`ROOM_ARCHIVE_PREVIEW_REQUIRED`. Занятая аудитория не может быть архивирована,
пока существуют активная группа, будущее занятие, активная серия/план или
конфликт расписания.

## Единый пользовательский сценарий

Production `BranchFormDialog` и вложенные room-диалоги локально проходят:

- создание трёх аудиторий вместимостью `1/2/8`;
- перечитывание всех трёх из API;
- изменение названия и вместимости парной аудитории `2 -> 3`;
- preview занятой ансамблевой аудитории с двумя будущими занятиями и
  недоступной кнопкой архивации;
- preview свободной индивидуальной аудитории с видимым перечнем сохраняемой
  истории;
- archive commit с `expectedVersion`, подтверждением, причиной и датой;
- исчезновение архивированной аудитории из рабочего списка при сохранении
  двух остальных.

## Backend/schema

Room lifecycle повторно проверяет все блокеры внутри versioned mutation,
обновляет только `app.rooms`, добавляет `app.room_lifecycle_history` и не
выполняет `delete from` для Lesson. Migration `0120` задаёт append-only trigger,
`on delete restrict` для журнала и не позволяет новым активным scheduling
references указывать на архивную аудиторию.
