# UAT-012 — десять связанных вкладок и desktop history

Статус: **PARTIAL**. Полный локальный Windows device-сценарий пройден;
production Release owner-повтор ещё не выполнен.

## Сквозной Windows-сценарий

`integration_test/v4_workspace_device_test.dart` открывает кликами по
подчёркнутым ФИО/названиям десять разных сущностей в реальном
`ProductionWorkspaceHost`:

1. ученик;
2. преподаватель;
3. занятие;
4. группа;
5. аудитория;
6. филиал;
7. постоянный план;
8. задача;
9. оплата;
10. пользователь.

Проверяется единый production-путь `EntityLinkText → navigateEntityLink →
WorkspaceNavigationScope → WorkspaceController`, а не прямое заполнение
состояния тестом. После десятого перехода исходная вкладка ученика остаётся на
месте, активна вкладка пользователя и виден canonical breadcrumb
`Настройки → Пользователь · Сидоров Алексей`.

В той же вкладке тест проходит breadcrumb в `Настройки`, затем UI-кнопки
`Назад` и `Вперёд`, возвращается в исходную вкладку без потери остальных
девяти, выполняет обычный restart без новой deep-link команды, восстанавливает
все десять вкладок и двухуровневую route history. Global logout очищает
account-scoped storage и убирает содержимое workspace.

Windows device: `1/1` PASS.

семантику и не подменяет её восстановлением сессии.
