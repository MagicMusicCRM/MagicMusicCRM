# UAT-095 — единая Lesson во всех представлениях

Дата: 2026-08-12
Статус матрицы: `PARTIAL` — локальная реализация и техническая проверка PASS,
production owner UI/API/DB evidence ещё не получены.

## Один канонический путь

Month, Week и оба Day-представления принадлежат одному `ScheduleWidget`.
Month сначала выбирает дату и переводит тот же state в Day; Week, Day по
аудиториям и Day по преподавателям передают Lesson в общий
`_showLessonDetails`, а действие `Перенести или изменить` всегда вызывает
`CreateLessonDialog.show`. Календарь карточки клиента встраивает тот же
`ScheduleWidget`, поэтому отдельного упрощённого редактора у него нет.

Tray постоянного Plan до исправления нарушал этот контракт:

- cursor-страница содержит bounded projection, а открытие искало полную Lesson
  только в коротком `fallbackLessons`;
- paged item вне fallback молча ничего не делал;
- карточка Group передавала пустой fallback и не передавала внешний callback,
  поэтому все её tray items были тупиковыми.

Теперь tray сначала использует уже загруженную Lesson, а при её отсутствии
делает точное `GET /crm/lessons?lessonId=...&limit=1` и открывает тот же
`CreateLessonDialog`. Новый параметр добавлен в существующий actor-scoped
endpoint, а не в параллельный detail API: Manager/Admin сохраняют свой scope,
Teacher видит только собственную Lesson, Client — только связанную. Terminal
state разрешён только для точного ID, чтобы ended tray мог открыть историю;
обычные списки по-прежнему исключают terminal cancellation/reschedule sources.
Если Lesson уже недоступна, UI явно предлагает обновить расписание вместо
молчаливого no-op.

## Back и сохранение контекста

Тёмный Windows device прошёл один непрерывный маршрут карточки клиента:

1. default-hide чужих занятий;
2. раскрытие чужих и отдельные target/other markers;
3. Week и Month;
4. Day по аудиториям, scroll к поздней Lesson;
5. quick view → `Перенести или изменить` → canonical editor;
6. Back в тот же Day с датой `вт, 4 августа 2026`, тем же раскрытым фильтром и
   тем же фактическим vertical scroll offset;
7. переключение на Day по преподавателям и открытие той же Lesson-reference с
   возвратом в сохранённый режим.

Windows evidence:

- [`lesson-canonical-editor.png`](lesson-canonical-editor.png) — полная форма
  с Client, Branch, Room, Teacher, датой, временем и frozen расчётными полями;
- [`lesson-editor-back-context-restored.png`](lesson-editor-back-context-restored.png)
  — после Back сохранены Day, дата, фильтр и позиция `20:00` в viewport.

Отдельный widget regression перелистывает Plan tray, открывает item, которого
нет в fallback, проверяет точный `lessonId`-запрос, видит тот же editor и после
Back получает прежний horizontal scroll offset. Тем самым покрыт и group path,
который не имеет внешнего callback.

## Защищённые команды

Entry point не получает собственного save endpoint и не обходит существующую
схему. Перенос/подмена из editor продолжают требовать reason, authoritative
signed preview, явное подтверждение, `expectedVersion` и idempotency identity;
отмена и расчёт используют тот же `LessonDecisionFlow`. Tray и календарь
только находят полную actor-scoped Lesson и открывают форму.
