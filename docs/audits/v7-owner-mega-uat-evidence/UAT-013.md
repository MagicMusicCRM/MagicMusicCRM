# UAT-013 — Android Back, keyboard, SafeArea и compact navigation

Статус: **PARTIAL**. Локальный Android 15/API 35 gate пройден; production
Release owner-повтор ещё не выполнен.

## Найденные и закрытые дефекты

1. `ProductionWorkspaceHost` не рисовал compact navigation, а вложенный
   `MessengerScreen` при `workspaceOwned=true` также её отключал. Teacher на
   телефоне оставался в Chat. Общая workspace-оболочка теперь владеет нижней
   навигацией `Чат / Расписание / Ученики`.
2. `MagicSheet` передавал `Duration.zero` в
   `DraggableScrollableController.animateTo`, когда Android или accessibility
   отключали анимации. Flutter падал assertion. Reduced-motion путь теперь
   немедленно использует `jumpTo`.

## Android 15 / API 35

- `v6_back_device_test.dart`: `1/1`. Реальные ADB `KEYCODE_BACK` последовательно
  закрывают partial sheet, dialog поверх full sheet, full sheet, вложенный
  route, dirty-form decision и только затем local history.
- `v6_expandable_sheet_device_test.dart`: `1/1`. Sheet раскрывается, keyboard
  не перекрывает sticky action, SafeArea/system inset соблюдены, сохранение
  закрывает поверхность.
- `v7_role_personas_device_test.dart`, UAT-141: `1/1`. Настоящий
  `TeacherDashboardScreen` проходит Chat → assigned Schedule → assigned
  Students через нижнюю навигацию; создание занятия и закрытые данные не
  появляются.

## Локальные регрессии

- `expandable_magic_sheet_test.dart` + `app_back_policy_test.dart`: `8/8`,
  включая новый reduced-motion zero-duration сценарий.
- `production_workspace_mount_test.dart`: `12/12`, включая compact Teacher
  switching.
- targeted Flutter analyze: PASS.

## Остаток до PASS

Owner должен повторить тот же набор в production Android Release: системный и
predictive gesture Back, реальная клавиатура, status/navigation bars, portrait/
landscape и Teacher/Client нижняя навигация. Production не изменялся.
