# UAT-120–123 — фильтры, scope, экспорты и поиск

Статус: **PARTIAL**. Это локальное техническое доказательство текущего
checkout, а не production owner-UAT. Production не изменялся.

## Что доказано

| ID | Проверка | Локальный результат |
|---|---|---|
| UAT-120 | Общие period/branch filters | Director-сценарий отправляет одинаковые `from`, `to` и `branchId` в client-status, lesson-success, school-finance, XLSX и CSV. После смены Branch все пять контрактов повторно проверены с новым UUID. |
| UAT-121 | Manager без school finance | В Manager-сеансе нет school-finance KPI, finance XLSX и финансового журнала; `/analytics/v4/school-finance` не запрашивается. PostgreSQL integration дополнительно доказывает `Forbidden` для Admin/Manager и branch-filtered данные для Director/system_admin. |
| UAT-122 | XLSX/CSV и сверка | XLSX открыт ExcelJS как валидный OOXML. XLSX и CSV имеют одинаковые колонки, число строк и кириллицу; CSV начинается с UTF-8 BOM. Finance XLSX сверен с source rows по revenue/expenses и формуле net. Flutter проверяет сигнатуру/BOM до записи и показывает, открыла ли файл ОС или только сохранила его по точному пути. |
| UAT-123 | Lead/Student/Teacher/Room/Lesson search | Канонический schedule search посимвольно сохраняет focus и введённый текст, расширяет диапазон через actor-scoped `/crm/clients/search` и точные `/crm/schedule/matrix` запросы с `leadId`, `studentId`, `teacherId` или `roomId`. Поиск занятия по дате переводит в точный Day; workspace view/date/vertical scroll не сбрасываются. Отдельный production Lead proof уже есть. |
