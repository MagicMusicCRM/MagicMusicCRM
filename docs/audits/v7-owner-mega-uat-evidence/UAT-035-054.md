# UAT-035–054 — локальный технический кандидат

Дата: `2026-08-12`
Среда: локальный Flutter/Windows runtime и локальный PostgreSQL
Production mutation/deploy: **не выполнялись**

Документ фиксирует техническую готовность сценариев G3–G5. Статус остаётся
`PARTIAL`, пока владелец не повторит обязательные действия на production и не
снимет требуемые UI/API/DB-доказательства.

## Закрытые разрывы

- Desktop-карточка получила постоянный левый rail: он не прокручивается вместе
  с длинным canvas. Компактная карточка по-прежнему использует вкладки.
- Manager теперь ограничен назначенными филиалами не только в списке групп, но
  и в прямом чтении/изменении состава группы, поиске учеников и серверном
  добавлении ученика по известному ID.
- В карточке клиента появились недостающие UI-действия существующего backend:
  назначение основного плательщика, просмотр и привязка app-user и отправка
  приглашения ученику.
- Lead/Student участники семьи отображаются как typed entity links, а не как
  непереходный текст.
- Для состава группы добавлен widget-regression: обычный ученик и ученик-
  плательщик, фактические add/remove запросы и readback.
